# 专业能力图谱探索式界面改版（第一轮原型）

以已合并PR10的最新main为基线。所有数据经GraphStore只读加载，没有重提能力、生成关系或修改研究成果。旧研究平台及完整研究审查页面保留为次级入口；侧栏平台入口选择“专业能力图谱”进入新空间。

## 改版前后与页面结构

新首页默认完整29个能力节点（3一级、9二级、17三级）和26条源层级边，无虚构根节点，无搜索或筛选器，无常驻右侧详情。横向三层布局，节点原编号及名称，缩放、拖动画布、适应画布与全屏保留。颜色区分类型，不表示能力水平。

单击节点高亮真实归属与下属路径，其他节点可见；先显示简洁信息卡，不自动跳转或打开证据。三级卡片通过明确按钮进入岗位或课程专题，两专题保留同一能力上下文。默认径向布局，只有源数据可展示的真实R02或R03边；空状态不造演示关系。A/B/C仅为岗位摘要证据性质，K1—K4为课程支撑功能。

源default_visible状态继续生效，B/C等默认隐藏记录并未删除，可从保留的“研究审查图谱”访问。新首页不提供状态筛选。某能力专题为空不表示没有全部研究记录或教学价值。

“完整课程知识体系”初始8项目，单击项目只显示卡片，按钮展开知识；R04保留原知识→项目方向，页面分组不反转研究语义。同一CK在多项目出现时共用同一ID；所有60知识点均可通过项目展开查看。点击知识点显示第一轮真实说明、功能标签和所属项目；已有支撑可反向进入对应能力课程专题，未关联知识继续保留。

## 交互与证据

节点点击与边点击为不同组件事件，均核对当前实际展示ID。点击边高亮两端及真实关系，简卡显示判断、分类、状态。点击“查看完整证据”才打开画布下方的证据抽屉。

抽屉使用Streamlit原生底部有边框固定高度容器（440像素，内部滚动），不是覆盖画布的浏览器固定弹层。包含关系概览、研究判断及原始证据三层；默认无JSON、长路径或完整证据。关闭只改变抽屉状态，不更换图谱键或选择。相同空间及中心的viewBox保存在组件中，开关抽屉保持位置。切换专题会清空旧关系证据，避免误显示其他关系；返回总览保留选中能力。

## 文件与启动

app/explorer_model.py只构建真实数据视图，app/explorer_page.py实现页面状态和底部证据；app/frontend/index.html新增探索渲染模式，复用原通信、样式与SVG辅助函数。app/main.py新增探索入口并保留研究审查入口；原competency_store及旧页面继续复用。新增app/tests/test_explorer.py；旧详细页面测试改为访问研究审查入口。没有增加依赖。

仓库根目录启动：

```bash
python -m pip install -r app/requirements.txt
python -m streamlit run app/main.py
```

选择专业能力图谱。Mac普通浏览器可运行；本轮实际使用Linux Chromium验证，并非真实Mac/电视硬件验收。全屏按钮扩大当前画布区域，保留缩放/适应按钮；全屏时如需阅读画布下方卡片及证据，应先退出全屏。电视鼠标单击支持，不依赖悬停完成核心操作。
