# 《数据库原理及应用》课程能力知识图谱

第四阶段本地研究展示原型。使用 Python、Streamlit 和原生 SVG/JavaScript 交互图，无需图数据库、付费服务或图谱 CDN。应用只读第三阶段 Excel，前两阶段和第三阶段输出均不写入。

## 启动

从仓库根目录运行，部署基线为 Python 3.12：

```bash
python -m venv .venv
source .venv/bin/activate
# Windows: .venv\Scripts\activate
python -m pip install -r app/requirements.txt
python -m streamlit run app/main.py --browser.gatherUsageStats=false
```

浏览器访问终端显示的地址，通常为 http://localhost:8501 。首次安装依赖需要网络，启动后图谱不需要外部脚本或云服务。必须保留完整仓库中的 `phase3/output/`，不能只下载 app 文件夹。

## Streamlit Community Cloud部署

仓库 `anyuchuan/python-automation`，分支 `main`（PR审核合并后），主程序 `app/main.py`；在 Advanced settings 明确选择 **Python 3.12**。已有3.14实例需要按平台说明重新部署才能更换解释器，单纯Reboot或修改requirements不能切换Python。完整设置、临时测试分支、日志排查及验证限制见 [中文部署说明](部署说明.md)。

## 数据与版本

自动只读加载 `phase3/output/` 下的知识图谱节点表、知识图谱关系表、职业能力课程匹配矩阵、课程能力覆盖与缺口分析四份 Excel。启动检查工作表、字段、唯一ID、端点、34×8项目单元、统计分母及来源指纹。`input_snapshot.json` 锁定 main 的 PR #3 已合并修订版；文件不同会明确报错，禁止静默回退到旧版5项直接支撑。合法更新源数据时须人工审阅版本、同步快照和版本测试。

实际读取：50岗位候选、79摘要任务、34三级能力、8教学项目；314原始节点、864候选关系、60隔离关系。修订版能力等级为直接支撑1、部分支撑18、未见明确支撑14、待人工审核1。完整来源提交和文件哈希在“来源与局限”页展示。

## 使用

- **研究总览**：研究流程、数量及文本支撑快照。
- **图谱探索**：检索编码、名称、来源；按类型、能力层级、项目和支撑等级筛选。默认以 N113 为中心展示两跳局部子图；可选任意岗位、任务、能力、项目或知识点为中心，也可查看筛选范围图。局部能力默认不扩展其他三级能力，防止读图混淆。
- 图中点击节点查看名称、编码、来源、证据、课程PDF物理页码、审核状态、相关节点和技术行为边界；点击连线查看原记录及原文/摘要。滚轮或按钮缩放，拖动画布平移，Tab/Enter 操作节点。
- **教学项目**：查看8项目各自的34能力单元、知识条目及项目内实操要求。32学时实践口径不额外叠加。潜在改进方向为全课程研究建议，没有擅自分配到具体项目。
- **支撑分析**：显示1/18/14/1及逐项行为边界。能力分母34、项目单元分母272、未见支撑分类分母14。文本匹配结果不是学生能力达成率或经核验行业需求覆盖率。
- **来源与局限**：版本、哈希、研究边界和全量/默认候选CSV下载。图谱页可下载当前筛选结果，截断时导出与画面一致。CSV为UTF-8 BOM，并对公式前缀做防执行转义。

## 证据与风险展示

默认候选视图259节点、450关系，**默认显示不等于已确认**。所有原始候选、摘要、研究推断、课程文本支撑、待审核状态均保留。含历史疑似标记、任务到能力含研究推断、旧编码映射和课程落点尚待判断的关系默认为高风险隐藏；60隔离关系独立隐藏。该风险规则是展示策略，不是新核验结论。

必须先开启“研究探索模式”，再单独开启“显示高风险推断”或“显示隔离关系”。探索仅改变可见性，不能升级证据。研究探索全量导出为314节点、924关系，保留风险说明。未见明确支撑只标能力状态，不虚构正向支撑边。历史遮挡课程候选不作已确认实训依据；本阶段不新增其核验任务，也不开展招聘原文核验。

图例：绿色实线为直接文本支撑；黄色虚线为部分支撑；紫色虚线为研究推断/待审核；红色点线为高风险/隔离；灰色能力状态为未见明确支撑。原始关系方向、类型可在连线详情及CSV查看。

## 测试

```bash
python -m unittest discover -s app/tests -v
```

包含数据完整性、版本防回退、风险双开关、筛选、局部邻域、CSV、证据页码、只读性、HTML转义和 Streamlit AppTest 页面交互测试。

可选真实浏览器冒烟测试：先启动应用，再安装 `playwright==1.62.0` 和可用 Chromium，运行：

```bash
CHROMIUM_PATH=/usr/bin/chromium python app/tests/browser_smoke.py
```

可用 `APP_URL` 指定地址。浏览器测试生成 `app/artifacts/` 截图和 `work/` 临时下载（先创建 work 目录）；不需要将浏览器依赖加入普通运行环境。已执行结果见 [验证报告](artifacts/验证报告.md)。

## 实现边界

布局为稳定的六类纵列，不使用复杂动画。可视节点上限20–120，超出会显示截断提示；完整数据可独立下载。探索开关、局部图和节点类型可能使历史数据暂不可见。岗位样本和109条疑似任务能力关系保留历史状态；本应用不逐条核验、不将核验作为后续阶段条件，不新增任何研究实体或支撑关系。
