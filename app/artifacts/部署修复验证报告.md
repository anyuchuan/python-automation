# Streamlit部署修复验证报告

日期：2026-10-22（北京时间）。基线：main `99d3b37188b13468e58928386e688784bee44c74`，PR #4已合并。

## 发现与结论边界

1. `app/requirements.txt` 已存在，Cloud按官方搜索顺序会优先使用它；原根目录只有openpyxl。根目录缺少Streamlit不是本次依赖卡顿的已确认原因，现以转发统一安装入口。
2. 原固定版本pandas 2.2.3没有CPython 3.14可用Linux wheel。`pip download --only-binary=:all: --no-deps --python-version 3.14 --implementation cp --abi cp314 --platform manylinux_2_17_x86_64 pandas==2.2.3`失败。修复后 `uv pip compile app/requirements.txt --python-version 3.14 --no-python-downloads --no-cache`明确报告pandas没有可用wheel。该检查针对目标版本解析，未实际运行3.14解释器或完整源码构建。
3. 现有日志停在Resolved，不能确认云端正在构建pandas，更不能排除下载、平台资源或其他后续安装问题。修复保留已有四个版本，部署基线改为明确选择Python 3.12，并要求二进制包以尽早暴露不支持的环境。
4. 路径基于`__file__`，所需四份修订Excel和来源快照均已在GitHub main。启动仅解析这些已生成Excel，缓存后不重读，不解析PDF、不执行前三阶段研究脚本。首次只读数据加载约0.19–0.26秒（本环境测量），与十分钟依赖等待不同阶段。
