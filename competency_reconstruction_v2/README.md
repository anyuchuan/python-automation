# 关系型数据库候选专业能力体系 V2

本目录是独立研究候选稿，保留原有3—9—17、65条岗位证据、60CK及全部图谱文件和Streamlit。基于main e65a059；不依赖径向界面PR #12，不修改该PR。

本轮筛查22条跨行业岗位记录：14条原始发布页、3条二次发布页可见文本核对，5条原页失败或正文缺失。纳入2条、条件纳入6条，背景保留5条、排除4条、待核验5条。仅8条用于有限任务分析，未达30—50有效样本参考目标。页面核对不等于岗位真实性或仍在招聘的外部认证。

候选结果为10项任务、4—9—13能力结构、21条跨行业任务能力关系、43条课程知识候选支撑、11条旅游任务应用候选。7项能力有明确数据库/SQL任务或要求依据，3项以关系型解释或业务任务推断为主，3项仅课程依据支持。岗位ABC与课程K1—K4独立，均不作能力得分。

## 运行

在仓库根目录，建议Python 3.11或3.12：

```bash
python -m pip install -r competency_reconstruction_v2/requirements.txt
python competency_reconstruction_v2/build.py
python -m unittest discover -s competency_reconstruction_v2 -p 'test_*.py' -v
```

可用`--output /tmp/v2-preview`生成至临时目录。生成器离线读取已审阅的结构化输入，不自动更新招聘页面。联网采集由本次研究过程执行，sources.json记录页面核对状态、URL、采集时间、发布信息、短摘录、段落定位、限制与转述；不是完整广告存档。以后补采必须重新打开原页，不能只改状态。

- sources.json：22条真实检索记录，含排除、待核验和条件纳入；未知日期为空。
- model_rules.json：逐条研究判断、任务片段、候选能力和新判断的课程/旅游关联。先任务、再能力、最后层级与旧版对照。
- build.py：构建13份Excel、2份研究说明及机器可读JSON；不会写入本目录外。
- protected_inputs.json：关键历史研究文件、PDF与应用代码的SHA256锁定。
- test_v2.py：来源状态、关系引用、层级、课程证据、语义重复、重生成及历史输入保护测试。
- output/：01—13 Excel、V2专业能力体系建模说明.md、跨行业岗位采集与证据限制说明.md、v2_research.json。
- 采集过程记录.md：检索范围与页面访问限制。
- 测试结果.txt：实际执行日志。

## 研究边界

8条有效分析资料不是样本饱和结论，且大部分附条件；运维行动高度依赖VJ011，需补充独立雇主。课程独立候选V2C011—013不得计入招聘需求。课程原文只支撑具体环节；没有进行完整能力培养判断、课程优劣评价或学生达成度计算。旅游50岗位仍未核验，48任务保留原摘要证据。新旧对照为范围对照，不迁移原判断或宣称等价。

17条已打开记录中3条是高校二次发布，原始企业直发身份未确认。本科岗位的技术环节可研究，不意味着高职毕业生满足招聘门槛。实际关系的技术实现、预期产物和评价依据均有研究推断，等待研究者和专家审查。
