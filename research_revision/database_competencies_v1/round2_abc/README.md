## 为什么任务类和关联类分别记录

A任务说明摘要明确了某个技术活动；若再细化成未写出的实现方法，该关联仍可只有B性质。例如数据库查询性能优化→索引调整，是B类技术解释，不是A类索引需求。SQL语境复杂取数→多表连接也是低充分性B备选，不能把复杂等同JOIN。

同一能力可以同时有A/B/C证据，如DB001查询提取。DB007表设计、DB009运行检查、DB012分组聚合、DB013质量核查等已进入候选结构，**不再隔离在结构之外**。条件和待审状态约束最终采用，不否定其候选资格。

“数据库更新”可有记录更新DB006或结构调整DB016等解释，原文还可能指版本升级；两个候选可以并存待审，但不能相加当作两项明示需求。DB001/DB017、DB005/DB011也存在目标与方法的包含交叉，需研究者审查最终层级，不计算独立岗位频次。

本轮A/B/C是岗位关联分类，**不是原表证据质量等级A/B/C**。所有岗位仍是未核验候选，A也只表示直接摘要支持，招聘原文已验证数仍为0。一般旅游服务、沟通营销、Python建模、BI展示或普通系统故障等不被强行解释成数据库活动。
