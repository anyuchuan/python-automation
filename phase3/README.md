# PR #3修订：聚焦课程能力图谱

按最新范围调整，本轮只复核34项三级能力与8个教学项目、知识点、课程原文和课程能力关系。保留既有50岗位、79任务、职业能力及109条推断关系的证据状态，但不再开展或新增招聘原文、109条关系核验任务，不以这些核验作为后续阶段或第四阶段前置条件。第13页历史标记和候选条目保留，本轮不再新增遮挡内容检查或核验要求。

## 复现

Python 3.10+，从仓库根目录运行：

```bash
python -m pip install -r phase3/requirements.txt
python phase3/build.py
python -m unittest discover -s phase3 -p 'test_*.py' -v
```

仍使用锁定的原数据和实际课程PDF。脚本检查输入指纹及结构一致性，这属于程序数据完整性检查，不是招聘真实性或109条关系的人工核验。课程PDF按正文自动识别，原文、物理页码和条目ID保留。默认输出phase3/output/，禁止覆盖前两阶段目录。

重运行会覆盖第三阶段同名文件，请另存已经人工填写的审核版本。相同输入与方案的单元格、统计和报告可重复，Excel压缩元数据不保证相同。

## 34×8项目复核

新增34×8视图和272行项目单元复核。能力整体等级按课程整体判断，项目层按各项目证据判断，不能直接复制。例如N113在项目五直接支撑，项目六仅有视图查询技术分项，项目层为部分支撑。

每单元包含项目、知识、实践ID与证据。项目教学内容引文只是审阅范围，不等于正向证据；未见明确支撑单元不生成支撑关系。N331和N512在目标层有提及但项目落点不明，各项目单元暂待审核；不能由目标直接推定8个项目已培养。项目单元分母为272，与34项能力分母分开。

## 14项未见支撑的研究建议分类

- 本课程潜在改进方向4项：N111、N121、N231、N521。
- 其他专业课程可能承担5项：N112、N124、N222、N232、N421。
- 旅游业务背景能力4项：N223、N224、N511、N531。
- 证据不足无法判断1项：N221。

分类分母为14，不是34。全部为研究建议，不是课程标准证明，也未核实其他课程实际开设、承担或覆盖情况；不将改进建议加入现行课标知识点。

## 方法与测试

`course_specs.json`依据实际PDF结构化，不添加原文外知识；`matching_plan.json`是逐项完整行为与技术子环节复核方案，非关键词自动定级、非专家审核结论。课程引文、页码、知识项目实践归属、节点唯一和关系端点持续检查。

测试覆盖7份Excel可打开、272单元完整性、四项降级、七项重点边界、14项分类、分母、课程证据与知识点ID、前后对照、历史数据状态不变、当前不新增招聘核验任务及重复运行。实际测试结果见output/测试结果.txt。后续只围绕课程项目、知识点、能力关系和学习评价继续建设，不把招聘原文核验设为进入第四阶段条件。
